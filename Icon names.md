# Icon names

Each style has two folders: `KOReader Icons` (KOReader's own icons, installed as they are) and `Base Icons` (every other drawing, once). The base icons are also the Quick Action icons, under their own names, except the few that only make sense inside a plugin. `install/manifest.lua` builds the SimpleUI, ZenOS and Project: Title packs from both folders. This page is the readable version: for each KOReader or base icon, the plugin pack icons made from it.

## Solar Colour

241 SimpleUI, ZenOS and Project: Title pack files are made from 147 of the 182 base icons and 23 of the 102 KOReader icons. The other base icons are only used as Quick Action icons.
